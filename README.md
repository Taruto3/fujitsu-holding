# 富士通 持株メモ（ブラウザ版）

個人利用向けのWebアプリです。富士通（6702）の保有株数、入力した株価、時価総額をブラウザ内に保存します。

## 機能

- 小数を含む保有株数の保存
- 直近で確定した終値の自動取得
- 時価総額の自動計算
- ブラウザ内への自動保存（localStorage）
- PWA対応・オフライン表示

## 公開URL

GitHub Pagesで公開します。ページを開くと `data/quote.json` に保存された直近の終値を読み込みます。

## ローカル起動

Node.js 18以上で次を実行します。

```sh
npm start
```

表示されたローカルURLをブラウザで開きます。

## 終値の更新

GitHub Actionsが平日16:10（日本時間）に富士通（6702.T）の確定済み日足終値を取得します。祝日や休場日は直近営業日の終値を維持します。Actions画面から手動実行することもできます。

## 注意

表示される株価・時価総額は参考値です。金融取引の判断には使用せず、証券会社などの公式情報を確認してください。このアプリは富士通株式会社の公式アプリではありません。
